# How-to-Customize-the-.NET-MAUI-Cartesian-Chart-Axis
 
The [.NET MAUI Chart](https://www.syncfusion.com/maui-controls/maui-cartesian-charts) control offers advanced customization options for its axes, allowing developers to tailor the appearance and behavior of axis labels according to their needs. This customization can be applied to [NumericalAxes](https://help.syncfusion.com/maui/cartesian-charts/axis/types#numerical-axis), [DateTimeAxes](https://help.syncfusion.com/maui/cartesian-charts/axis/types#datetime-axis), [CategoryAxis](https://help.syncfusion.com/maui/cartesian-charts/axis/types#category-axis) and [LogarithmicAxes](https://help.syncfusion.com/maui/cartesian-charts/axis/types#logarithmic-axis). Below are some of the key features for customizing chart axes.

**Label Formatting**

Label formatting allows you to change how data labels appear on the axes. This is useful for making the data more readable and presentable. You can apply custom formats such as currency, percentage, or custom string formats.

**Label Rotation**
Label rotation is essential when dealing with a large number of labels or long label text, as it improves readability by rotating the label text at a specified angle.

Besides formatting and rotation, you can also adjust other label properties such as font size, color, and style to make the chart more visually appealing and informative.

## Troubleshooting
Path too long exception

If you are facing a path too long exception when building this example project, close Visual Studio and rename the repository to short and build the project.
